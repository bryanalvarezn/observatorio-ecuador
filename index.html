🔬 Metodología

El siniestro constituye la unidad macro del evento observado por el Observatorio.

Un mismo siniestro puede involucrar a una o varias personas. Por esta razón, las estadísticas principales contabilizan eventos únicos y no filas individuales de personas.

La base histórica ha sido estructurada para permitir posteriormente el análisis de relaciones entre evento primario, factores ambientales, factores humanos, características territoriales y consecuencias.

La clasificación de montaña utiliza la altitud y distingue entre Baja Montaña, Media Montaña y Alta Montaña de acuerdo con la clasificación establecida para el proyecto.

🧭 Principios del proyecto

El Observatorio busca desarrollar una infraestructura de conocimiento abierta, acumulativa, transparente y reproducible.
